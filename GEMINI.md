# Antigravity Rules & Frontend Design Guidelines

## Web & UI Design Rules
1. **NO Eyebrow Tags or Pill Subtitles Above Headings**:
   - NEVER create mini-subtitles, pill badges, category pills, or tag labels above section headings (such as `<div class="section-tag">...</div>`, `<span class="badge">...</span>` placed directly above an `<h2>` or `<h3>`).
   - Section headers must go straight to the point: start directly with the main title (`<h2>` or `<h1>`) followed by an optional concise description paragraph below it.

2. **Clean Typography & Layout**:
   - Keep titles clean, prominent, and direct.
   - Do not clutter section introductions with unnecessary category pills or eyebrow subtitles.
